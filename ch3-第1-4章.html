P9 · 2-3-1 算术运算符 & 字符串连接符 运算符 · 13:30

📌 核心考点

  • 数值运算符：+ - * / // % **

🚨

💡
易错 / 要点：字符串是不可变对象，s[0]="x" 会报错，必须用 s = s[:i]+"x"+s[i+1:] 或 replace()。
💡
易错 / 要点：字符串拼接用 + 或 join()，不要在循环里反复 +（性能差）。

    x = "outer"

    inner()
    print(x)

📌 核心考点

  • print() 默认 end="\n"
  • 不换行：print(x, end="")
  • 分隔符：print(1, 2, 3, sep=", ") → "1, 2, 3"
📂 no_newline.py复制
# 打印直角三角形
for i in range(1, 6):
    print("*" * i)
# *
# **
# ***
# ****
# *****

# 同行的
for i in range(1, 6):
    print("*" * i, end=" | ")
print()
💡
速记：end=""(字符串) → 不换行；sep=", "(分隔符) → 控制多项之间的间隔。
💡
易错 / 要点：易错：print("hi", end="") 不换行，但下一行 print 不受影响（每个 print 自己决定 end）。
