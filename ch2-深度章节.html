🧪 操作题到底长什么样

来看一道典型的 基本操作题（5 分），熟悉下套路：

📂 考生文件夹/PY101.py复制
# 题目：请写代码替换横线，不修改其他代码，实现以下功能：
# 从键盘输入一个小于 100 的正整数，
# 计算 1 到该数的累加和，并以 "result=xx" 格式输出。
# 提示：使用 input() 和 eval()，注意类型转换。

x = input("请输入一个小于 100 的正整数：")  # input 进来是字符串
n = eval(x)                                          # eval 把它转成整数

total = 0
i = 1
while i <= n:
    total = total + i
    i = i + 1

print("result=" + str(total))
🚨
3 个最易错的坑：① 直接 x > n比较 input 拿到的字符串，类型错；② 用 range(1, n+1) 而不是 while，老师在视频里也提了；③ 输出格式必须是 "result=xx"，一定要先 str()。

👋 一句话看懂这节：程序的"骨架"

Python 程序的最小可运行单元包含 6 件事：缩进、注释、变量、命名、保留字、连接符。 老师在这一节把它们拆开了揉碎讲，先把这 6 个挂在脑子里，后面所有 P 都是它们的排列组合。

📏 缩进 = Python 的灵魂

不像 C 用 { }，Python 用缩进表达代码块。4 空格或1 个 tab，但一个文件里不能混用。

📂 indent_demo.py复制
for i in range(3):      # 这一行末尾的冒号表示下面要缩进
    print(i)             # 同一缩进 = 同一个代码块
    if i % 2 == 0:
        print("偶数", i)
print("done")            # 这个 print 不属于 for 块
🚨
缩进错误三大类型：① IndentationError: unexpected indent（莫名其妙多缩进）② IndentationError: expected an indented block（该缩进没缩进）③ TabError: inconsistent use of tabs and spaces（tab 和空格混用）。考试里出错了直接重打代码块。

🏷️ 变量 & 命名（蛇式 vs 驼峰）

Python 命名规范：字母/数字/下划线，不能以数字开头，不能是关键字。
风格推荐：变量和函数用 snake_case（小写+下划线），类用 PascalCase（首字母大写）。

📂 naming.py复制
# ✅ 合法命名
student_name = "张三"
_score = 95
MAX_SIZE = 100           # 常量全大写

# ❌ 非法命名
# 1score    = 90      # 数字开头，SyntaxError
# class     = "A"     # class 是关键字
# my-name   = "tom"   # 短横线 - 会被当成减号

print(student_name, _score, MAX_SIZE)
💡
老师的小窍门：下划线开头（如 _score）是"内部变量"的约定俗成， 双下划线（如 __init__）是魔法方法用的，不要自己起名字。

🎤 注释 = 给未来的你看

类型写法作用示例
单行# ...行尾注释，# 后面的全是说明x = x + 1 # 计数
多行""" ... """ 或 ''' ... '''三引号包起来，常用于函数 docstring"""计算累加和"""
📂 comment_demo.py复制
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# ↑ 以上两行是编码声明，国二考试常见

"""
计算 1 到 n 的累加和。
参数: n - 正整数
返回: 累加结果
"""

def sum_to(n):
    """简洁 docstring：求 1+2+...+n"""
    total = 0
    for i in range(1, n+1):
        total += i              # 累加
    return total
📌
考试实测过的坑：中文注释在 Python 3 里默认无 BOM 即可， 但老考试系统（Windows 7 + IDLE）有时会傻乎乎报 SyntaxError: Non-UTF-8， 解决办法是在文件头加 # -*- coding: utf-8 -*-。

📦 赋值语句：7 种写法

国二选择 + 操作题都爱考链式赋值和解包赋值：

📂 assign_demo.py复制
# 1. 基本赋值
x = 10

# 2. 链式赋值
a = b = c = 100

# 3. 解包赋值（序列赋值）
x, y, z = 1, 2, 3
first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)   # 1 [2,3,4] 5

# 4. 复合赋值
count = 0
count += 1     # 等价于 count = count + 1
count -= 2

# 5. 海象运算符（Python 3.8+，考试可能出现）
if (n := len("hello")) > 3:
    print(f"长度是 {n}")

# 6. 全局变量声明（4 章会用）
global FLAG
FLAG = True
🚨
两个高频坑：
① a = b = c = [] 三者共享同一个列表，改 a 会影响 b 和 c！想分开要用 a, b, c = [], [], []。
② x, y = 1, 2, 3 会 ValueError: too many values to unpack。

🗣️ 三个输入输出函数（必背）

函数作用关键点示例
print()输出到控制台默认换行，end 参数改结尾print("hi", end="")
input()从键盘读一行一定返回字符串！s = input("提示：")

📂 io_demo.py复制
# 经典 input + eval 组合：题目要求"输入一个整数"
n = eval(input("请输入一个整数："))
print("你输入的是：", n, "类型是", type(n))

# 多个数值怎么输入？
# 例如输入 "10 20 30"
a, b, c = map(int, input().split())
print(a, b, c)            # 10 20 30

# print 不换行 (P4-4 会再展开)
for i in range(3):
    print(i, "|", end="")  # 输出 "0 |1 |2 |"
📌
题海战术总结：input 默认返回 str，最常见的丢分原因
① x = input(); print(x * 2) 输入 5 得到 55 而不是 10 ← 字符串重复 2 次。
② x = input(); y = x + 1 直接报 TypeError。
记住一句口诀："input 必转，eval 一行"。

🔗 引用 vs 复制（理解就够，选做题会出现）

📂 reference.py复制
a = [1, 2, 3]
b = a            # b 和 a 指向同一个列表（引用）
b[0] = 999
print(a)        # [999, 2, 3] — a 也被改！

# 想真复制，用 copy()
a = [1, 2, 3]
b = a.copy()
b[0] = 999
print(a)        # [1, 2, 3] — a 没变

# 数字类型没这个问题（不可变对象）
x = 10
y = x
y = 20
print(x)        # 10 — 数字是「值传递」
⚡
考试中的实际陷阱：操作题里老师经常把 list1 = list2 当 "备份"， 学生在 list2.append(...) 后惊讶于为什么 list1 也变了。这道题考过， 答案就一句话——列表是引用赋值。
