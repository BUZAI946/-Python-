P29 · 5-1 字符串操作符 字符串 · 05:33

📌 核心考点

  • in / not in：子串判断
  • + *：连接 + 重复
  • == < > <= >=：ASCII 顺序比较字符串
📂 str_op.py复制
print("ab" in "abcde")        # True
print("y" not in "xyz")      # False
print("hi" * 3)               # "hihihi"
print("apple" < "banana")     # True — 字母顺序
⚡
陷阱：字符串比较是按 字符编码逐位 比，所以 "Apple" < "apple"（大写字母编码小）。
💡
易错 / 要点：字符串是不可变对象，s[0]="x" 会报错，必须用 s = s[:i]+"x"+s[i+1:] 或 replace()。
💡
易错 / 要点：字符串拼接用 + 或 join()，不要在循环里反复 +（性能差）。

P30 · 5-2-1 索引与切片 字符串 · 18:16

📌 核心考点

  • 正索引：从 0 开始；负索引：从 -1（最后一个）开始
  • 切片语法：s[start:end:step]（含 start 不含 end）
  • 越界不会报错，自动截到边界
  • 典型用法：s[::-1] 反转；s[::2] 隔一个取一个
📂 slice.py复制
s = "Python编程"
print(s[0], s[-1])          # P 编
print(s[0:2])                  # Py
print(s[::-1])                  # 程编nohtyP —— 反转
print(s[6:])                   # "编程"

# 经典考题：每两个字符分开
print(s[::2])                  # Pto编
📌
必背：s[::2] 是"从 0 开始每 2 个取 1 个"（step=2），不是相邻两个一组。考试必考。
💡
易错 / 要点：字符串/列表索引从 0 开始，-1 是最后一个。越界会报 IndexError。
💡
易错 / 要点：切片 s[start:end:step]，end 不包含（左闭右开）。s[:] 复制整个序列。

P36 · 5-4-1 format 格式化 1 字符串 · 09:02

📌 核心考点

  • "{} {}".format(a, b)：默认顺序
  • "{1} {0}".format(a, b)：索引
  • "{name} is {age}".format(name="X", age=20)：关键字
  • f"... {a} ..."：f-string 推荐（Python 3.6+）
📂 fmt.py复制
name, age = "张三", 20
print("{} 今年 {} 岁".format(name, age))
print(f"{name} 今年 {age} 岁")       # 推荐写法
print(f"π 约 {3.1415926:.2f}")        # π 约 3.14 —— 保留 2 位小数
📌
必背：考试输出要求带格式（"result=xx"），用 f-string 写最简洁；老题用 format()。
💡
易错 / 要点：format() 调用前必须有字符串字面量（有引号包着的）或字符串变量，否则报错。
💡
速记："{0} {1}" 和 "{1} {0}" 顺序相反，索引是从 0 开始的。

📌 核心考点

  • 对齐 + 类型组合：例如 {:*^10.2f}
  • 进制转换：255:b = "11111111"，255:#x = "0xff"
  • str.format_map(dict) 用字典映射
📂 fmt3.py复制
print(f"{0.5:*^10.2f}")             # ****0.50****
print(f"{255:#x}")                 # 0xff
print(f"{1024:#o}")                # 0o2000

d = dict(name="李四", score=95)
print("{name}: {score}".format_map(d))   # 李四: 95

速记：f-string 简写 {var}；占位符 {var:<10.2f} = 【填充】【对齐】【宽度】【.精度】【类型】从左到右读。

易错 / 要点：f-string（Python 3.6+）是最现代格式化：f"Hello {name}, age={age+1}"。
